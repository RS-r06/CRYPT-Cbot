# GreenCoin Guide 🌱💰  
Your First AI-Powered Crypto Sidekick!

## Overview  
GreenCoin Guide is a beginner-friendly, rule-based chatbot designed to offer personalized cryptocurrency advice based on **profitability** and **sustainability**. Built in Python, this chatbot uses simple logic to help users identify coins worth exploring for long-term growth or environmental mindfulness.

## Features  
✅ Rule-based decision making  
✅ Analyzes trends and eco-impact  
✅ Conversational personality  
✅ Runs in your terminal with Python  

## Getting Started  
1. Clone the repo  
2. Open in Visual Studio Code  
3. Run `chatbot.py` and start asking crypto questions!

```bash
python chatbot.py
